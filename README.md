## What we do

IRCC Ready Docs is a **free companion** for IRCC online uploads: you open a tool (or a guide), fix the stuck step (too big, will not merge, wrong photo), and download a file that is closer to what the portal expects.

We do **not** replace IRCC, lawyers, or consultants. We **surface common upload rules** in tools and guides you can actually use. Official instructions on canada.ca always win.

Tools run **in your browser**. Application files are not uploaded to a GetNorthPath server when you compress, merge, flatten, or check them.

## How it works

```
1. Open the hub              →  No signup
2. Pick the stuck step       →  Too big, won't merge, wrong photo
3. Run the tool in-browser   →  File stays on your device
4. Read the matching guide   →  Why the portal rejected it
5. Optional next step        →  Form, checklist, template, or a free consult
```

## Who it’s for

- **Applicants** hitting IRCC upload errors (4 MB caps, merge failures, photo rejections)
- **People preparing IMM forms** who need to flatten before merge
- **Applicants comparing checklists or country tips** before they assemble a package
- **Community helpers and consultants** who need a shareable, cited reference for common IRCC upload constraints

> *Not affiliated with IRCC or the Government of Canada. Tools are helpers. canada.ca and the form instructions you are filing prevail if anything disagrees.*
