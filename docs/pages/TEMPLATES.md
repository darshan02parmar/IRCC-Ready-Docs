# Templates

**Nav landing:** [https://docs.getnorthpath.com/#templates](https://docs.getnorthpath.com/#templates)

**Nav:** Templates

Free templates with a real download. Each page shows what to expect on upload and links to the tool you need when the file does not fit (compress, merge, sign, flatten, visa photo).

Templates are **not** official IRCC forms. Always use the current form from canada.ca when filing.
