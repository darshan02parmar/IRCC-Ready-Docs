# Document workflows

Typical sequences when something fails an IRCC upload. Each path links to live tools and guides on [docs.getnorthpath.com](https://docs.getnorthpath.com).

These are helpers, not a guarantee of acceptance. Official form instructions win. See [RULES.md](RULES.md).

---

## File too big

1. [Compress PDF to 4 MB](https://docs.getnorthpath.com/compress-pdf-to-4mb) (or [Compress Image](https://docs.getnorthpath.com/compress-image) for JPG/PNG)
2. Pick the target that matches the field (4 MB default; 2 MB or 1 MB when needed)
3. Optionally confirm with [IRCC File Checker](https://docs.getnorthpath.com/ircc-file-checker)

Read: [IRCC file size limit](https://docs.getnorthpath.com/guides/ircc-file-size-limit) · [Compress a PDF for IRCC](https://docs.getnorthpath.com/guides/compress-pdf-for-ircc)

---

## Many files, one checklist slot

1. [Merge PDF](https://docs.getnorthpath.com/merge-pdf) into one file per slot
2. Optionally [Add Page Numbers](https://docs.getnorthpath.com/add-page-numbers)
3. [Compress PDF to 4 MB](https://docs.getnorthpath.com/compress-pdf-to-4mb) if the merge went over the limit
4. Optionally [IRCC File Checker](https://docs.getnorthpath.com/ircc-file-checker)

Read: [Combine documents for IRCC](https://docs.getnorthpath.com/guides/combine-documents-ircc)

---

## IMM form will not merge

1. Download and complete the current form from [IRCC forms](https://www.canada.ca/en/immigration-refugees-citizenship/services/application/application-forms-guides.html)
2. Validate the form where the instructions require it
3. [Flatten IMM Form](https://docs.getnorthpath.com/flatten-imm-form)
4. [Merge PDF](https://docs.getnorthpath.com/merge-pdf) with supporting documents
5. Optionally [e-Sign PDF](https://docs.getnorthpath.com/sign-pdf) or [IRCC File Checker](https://docs.getnorthpath.com/ircc-file-checker)

Read: [Why IMM forms will not merge](https://docs.getnorthpath.com/guides/cannot-merge-ircc-forms) · Form hubs: [/forms](https://docs.getnorthpath.com/#forms)

---

## Wrong visa photo crop

1. [Canada Visa Photo](https://docs.getnorthpath.com/canada-visa-photo) (or [Resize Image](https://docs.getnorthpath.com/resize-image) for exact pixels)
2. Optionally [Compress Image](https://docs.getnorthpath.com/compress-image) if the file is over the image size limit
3. Optionally [IRCC File Checker](https://docs.getnorthpath.com/ircc-file-checker)

Read: [Canada visa photo requirements](https://docs.getnorthpath.com/guides/canada-visa-photo-requirements) · Template: [visa photo crop guide](https://docs.getnorthpath.com/templates/visa-photo-guide)

---

## Phone scan to upload-ready PDF

1. [Crop & Clean Scan](https://docs.getnorthpath.com/crop-scan)
2. [JPG / PNG to PDF](https://docs.getnorthpath.com/jpg-to-pdf) (optional auto-compress to 4 MB)
3. Optionally [Rotate PDF](https://docs.getnorthpath.com/rotate-pdf) or [Merge PDF](https://docs.getnorthpath.com/merge-pdf)
4. [Compress PDF to 4 MB](https://docs.getnorthpath.com/compress-pdf-to-4mb) if still over the limit
5. Optionally [IRCC File Checker](https://docs.getnorthpath.com/ircc-file-checker)

Read: [Scan documents with a phone](https://docs.getnorthpath.com/guides/scan-documents-phone-ircc)

---

## Before you upload (final pass)

1. Confirm format and size against the form instructions
2. Run [IRCC File Checker](https://docs.getnorthpath.com/ircc-file-checker)
3. Fix fails with Compress, Flatten, or Merge as needed

Read: [Best free tools for IRCC documents](https://docs.getnorthpath.com/guides/best-tools-ircc-documents)
