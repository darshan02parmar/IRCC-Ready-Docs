# Features

Everything the public IRCC Ready Docs site ships today. Paths are English (unprefixed). French uses `/fr` (example: [/fr/guides/ircc-file-size-limit](https://docs.getnorthpath.com/fr/guides/ircc-file-size-limit)).

Base URL: [https://docs.getnorthpath.com](https://docs.getnorthpath.com)

---

## Tools

**15 live tools.** Word to PDF is planned but not shipped yet.

| Tool | Path | What it does |
| --- | --- | --- |
| Compress PDF to 4 MB | [/compress-pdf-to-4mb](https://docs.getnorthpath.com/compress-pdf-to-4mb) | Re-render a PDF until it fits under a chosen size (4 MB IRCC default; 2 MB and 1 MB presets) |
| Merge PDF | [/merge-pdf](https://docs.getnorthpath.com/merge-pdf) | Combine multiple PDFs into one file for a checklist slot |
| Flatten IMM Form | [/flatten-imm-form](https://docs.getnorthpath.com/flatten-imm-form) | Flatten AcroForm fields so IMM forms merge like normal PDFs |
| Split PDF | [/split-pdf](https://docs.getnorthpath.com/split-pdf) | Extract selected pages by thumbnail or page range |
| Canada Visa Photo | [/canada-visa-photo](https://docs.getnorthpath.com/canada-visa-photo) | Crop to the 35×45 mm ratio and export at IRCC pixel sizes |
| Crop & Clean Scan | [/crop-scan](https://docs.getnorthpath.com/crop-scan) | Crop phone scans and auto-clean shadows |
| JPG / PNG to PDF | [/jpg-to-pdf](https://docs.getnorthpath.com/jpg-to-pdf) | Build a PDF from images with optional auto-compress to 4 MB |
| PDF to JPG | [/pdf-to-jpg](https://docs.getnorthpath.com/pdf-to-jpg) | Export each PDF page as a JPG |
| Rotate PDF | [/rotate-pdf](https://docs.getnorthpath.com/rotate-pdf) | Rotate all pages or a chosen range |
| e-Sign PDF | [/sign-pdf](https://docs.getnorthpath.com/sign-pdf) | Draw, type, or upload a signature, then place it on the page |
| Edit & Annotate PDF | [/edit-pdf](https://docs.getnorthpath.com/edit-pdf) | Stamp a short note or date onto a chosen page |
| Resize Image | [/resize-image](https://docs.getnorthpath.com/resize-image) | Resize to exact pixels, including visa-photo presets |
| Add Page Numbers | [/add-page-numbers](https://docs.getnorthpath.com/add-page-numbers) | Number pages in a merged submission binder |
| Compress Image | [/compress-image](https://docs.getnorthpath.com/compress-image) | Shrink a JPG or PNG toward a target file size |
| IRCC File Checker | [/ircc-file-checker](https://docs.getnorthpath.com/ircc-file-checker) | Pass/fail format, size, and heuristic form-field checks in-browser |

| Coming soon | Path | Notes |
| --- | --- | --- |
| Word to PDF | `/word-to-pdf` | Not live; do not treat as a working tool |

All-in-one catalog: [/northpath-docs-app](https://docs.getnorthpath.com/northpath-docs-app)

See [WORKFLOW.md](WORKFLOW.md) and [pages/TOOLS.md](pages/TOOLS.md).

## What we deliberately do not add

- Paywalls on the core tools
- Claims that this site is an official IRCC product
- Guarantees that a compressed or flattened file will be accepted
- Listing unfinished routes (`/word-to-pdf`, `/coming-soon`) as live tools
